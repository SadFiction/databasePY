# databasePY

  DatabasePY allows the user to well... create entries (categorised in Directories
  ) in a local database for personal use to organise information.

## First run instructions

1. Clone this repository somewhere 
2. Python ( ignore this if you have it installed):
    1. goto https://www.python.org/ and download python
    2. run the setup executable and install
    3. done :)
4. Run Database.py ( this is just for the first time) and checkout some of the sub-commands(optional)
5. Now you can use the __database__ command in the terminal to manipulate data in your local database


## Further info

### Location of data

   Data is stored in %appdata% of the current user. 
   There's is a directory for each dir you create with the database command in the %appdata%.
   The above mentioned dir will store directories for the entries you have created which in
   itself store the items you have added to the entry and the main.txt file.
